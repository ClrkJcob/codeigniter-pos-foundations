# CodeIgniter POS Foundations

A basic four-page Point-of-Sale system created using CodeIgniter 4.

## Pages

- Home: `/`
- About: `/about`
- Customer Accounts: `/customers`
- User Accounts: `/users`

## Features

- CodeIgniter 4 routing
- Controllers and views
- Navigation links
- Static PHP arrays
- Foreach loops for customer and user records

## Database

This version does not use a database. Customer and user records are stored in static PHP arrays. A database will be introduced in the next module.
